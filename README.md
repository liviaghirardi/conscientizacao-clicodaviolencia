## 📖 Sobre o Projeto

O **CICLO** é uma plataforma web informativa focada na conscientização sobre a violência contra a mulher. O objetivo principal é educar o público de que a violência nem sempre começa com agressões físicas, detalhando o "Ciclo da Violência" e fornecendo informações cruciais sobre redes de apoio.

O design foi pensado para ser acolhedor, limpo e direto, priorizando a segurança e a clareza da informação para quem busca ajuda.

## ✨ Funcionalidades

- **Botão "Sair Rápido" (Quick Exit):** Um botão fixo de segurança que redireciona a usuária imediatamente para um site neutro (Google) e substitui o histórico da aba, protegendo-a caso alguém se aproxime repentinamente.
- **Design Responsivo:** Interface 100% adaptável para dispositivos móveis, tablets e desktops.
- **Navegação Suave (Smooth Scroll):** Transições fluidas ao clicar nos links do menu.
- **Detalhamento das Violências:** Páginas modulares dedicadas a explicar de forma profunda as cinco formas de violência previstas na Lei Maria da Penha (Física, Psicológica, Sexual, Moral e Patrimonial).
- **Rede de Apoio:** Acesso rápido aos principais canais de denúncia e acolhimento (180, 190 e CVV).

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando a base clássica do desenvolvimento web, sem o uso de frameworks complexos, focando em performance e acessibilidade:

- **HTML5:** Semântica e estruturação do conteúdo.
- **CSS3:** Estilização, layout em Flexbox/Grid e responsividade (Media Queries).
- **Vanilla JavaScript:** Lógica do botão de segurança e navegação interna.
- **FontAwesome:** Biblioteca de ícones para interface.
